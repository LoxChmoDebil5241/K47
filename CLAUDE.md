# K47 — 3D хоррор-новелла (веб + Android APK)

## Суть
Игрок сидит в тёмной бетонной комнате. Камера от первого лица, без ходьбы — только поворот головы (360°).
- Прямо: терминал (ЭЛТ-монитор) — на нём идёт сама новелла.
- Справа: стол с блокнотом — заметки/улики, открываются кликом.
- В терминале 48 глав, в 47 из них — разные мини-игры (`docs/Minigames.md`).
- Сзади: проход в тёмный коридор — источник угрозы.
- Слева: стена — место для скримеров, надписей, изменений окружения.
Полный дизайн: `docs/GDD.md`.

## Стек
- Three.js + Vite, чистый JavaScript (ES-модули).
- Android: Capacitor оборачивает `dist/` в APK. Папка `android/` не хранится в git — её генерирует CI.
- CI: `.github/workflows/android.yml` — после каждого пуша собирает APK и публикует в GitHub Releases.
- Все текстуры пока процедурные (canvas), позже заменяются ассетами из `public/`.
- Текст книги: `src/story/book.json` (пролог + 48 глав). Мини-игры: `docs/Minigames.md`.

## Команды
- `npm run dev` — локальный сервер разработки.
- `npm run build` — сборка в `dist/`.
- Проверка: запустить `npx vite preview` и сделать скриншоты через Playwright
  (`executablePath: '/opt/pw-browsers/chromium'`, флаги swiftshader для WebGL).

## Структура
```
src/
  main.js       рендер, камера, ввод, цикл
  room.js       геометрия комнаты, свет, точки фокуса
  terminal.js   ЭЛТ-терминал: canvas-текстура, меню архива, чтение глав
  textures.js   процедурные текстуры (бетон, лёд, бумага)
  style.css     оверлеи: зерно, виньетка, кнопки
  story/        данные сюжета
  minigames/    (будет) мини-игры терминала, общий интерфейс
docs/           GDD, список мини-игр
```

## Правила кода
- Один модуль — одна система. Комментарии короткие, на русском.
- Сюжет и тексты — в данных (`src/story/`), не в коде.
- Управление должно работать и пальцем (телефон), и мышью.
- Комментарии и тексты игры — на русском.

## Как работаем
Пользователь пишет с телефона и присылает файлы в чат.
Claude проверяет каждое изменение скриншотами в headless Chromium перед пушем.
Пользователь тестирует APK из GitHub Releases на своём телефоне.
Визуальный референс (старая версия) — сделан «топорно»; делаем с нуля и красиво.
