# K47 — 3D хоррор-новелла (веб + Android APK)

## Суть
Игрок сидит в тёмной бетонной комнате. Камера от первого лица, без ходьбы — только поворот головы (360°).
- Прямо: терминал (ЭЛТ-монитор) — на нём идёт сама новелла.
- Справа: металлический стол (как в референсе) с креслом: блокнот, фото в рамке, гарнитура, рация, мелочи.
- В терминале 48 глав, в 47 из них — разные мини-игры (`docs/Minigames.md`).
- Сзади: шлюз в стиле SS14 (открывается нажатием) в тёмный коридор — источник угрозы.
- Слева: обычная бетонная стена с доской фото предшественников — место для скримеров и изменений окружения.
Полный дизайн: `docs/GDD.md`.

## Стек
- Three.js + Vite, чистый JavaScript (ES-модули).
- Android: Capacitor оборачивает `dist/` в APK. Папка `android/` не хранится в git — её генерирует CI.
- CI: `.github/workflows/android.yml` — после каждого пуша собирает APK и публикует в GitHub Releases.
- Все текстуры пока процедурные (canvas), позже заменяются ассетами из `public/`.
- Текст книги: `src/story/book.json` (пролог + 48 глав). Мини-игры: `docs/Minigames.md`.

## Команды
- `npm run dev` — локальный сервер разработки.
- `npm run build` — сборка в `dist/`.
- Проверка: запустить `npx vite preview` и сделать скриншоты через Playwright
  (`executablePath: '/opt/pw-browsers/chromium'`, флаги swiftshader для WebGL).

## Правила кода
- Один модуль — одна система. Комментарии короткие, на русском.
- Сюжет и тексты — в данных (`src/story/`), не в коде.
- Управление должно работать и пальцем (телефон), и мышью.
- Навигация — пиксельными кнопками внизу во всю ширину (как в референсе), палец — только небольшой осмотр.
- Кнопки подсвечиваются только в момент нажатия — ничего не «мигает», будто игра требует нажать.
- На столе кнопки только «Отойти» и «Открыть блокнот»; остальные предметы — нажатием прямо на предмет.
- Для автотестов есть `window.__k47` (`where(имя)`, `view`, `moving`).
- Шрифты встроены через `@fontsource` (работают офлайн): Press Start 2P — UI, PT Mono — тексты, Caveat — почерк.
- Звук (всё синтез в `audio.js`): 8-бит — ТОЛЬКО кнопки навигации, взаимодействия и «речь» надписей. Всё остальное (шаги, предметы, окружение, шлюз) — реалистично, если пользователь не укажет иначе.
- Реплики персонажа и мысли — `ui/say.js` (пиксель, по буквам). Страх темноты и гибель — `dread.js`.
- Комментарии и тексты игры — на русском.

## Как работаем
Пользователь пишет с телефона и присылает файлы в чат.
Claude проверяет каждое изменение скриншотами в headless Chromium перед пушем.
Пользователь тестирует APK из GitHub Releases на своём телефоне.
Визуальный референс (старая версия) — сделан «топорно»; делаем с нуля и красиво.

## Прогресс игры
- Код терминала: 4 цифры на корпусе монитора + 4 на стикере + 4 в темноте: у терминала посмотреть влево, на 4-й секунде проступают только цифры (без мыслей и без гибели). `state.js → codeParts()`.
- Износ носителя `screen` 0–100: победа в испытании +6, поражение −5. Режим чтения — без испытаний.
- Терминал: код → «Системное предупреждение» → «Соглашение» (3 галочки, «Принять всё» активна только со всеми) → меню 4 файлов с большими ◀ ▶.
- Файл → экран чуть приближается → окно как в референсе (статус, «Глава — игра», искажённый фрагмент, условия, «Читать повреждённым» / «Восстановить»).
- «Влёт»: «Восстановить» и «Читать» — камера ускоряется в экран с дрожью и вспышкой, дальше полноэкранный режим. Пока вместо мини-игр — 5 касаний за 5 секунд (на весь экран, `ui/reader.js → game`). Непрочитанный/невосстановленный файл читается «повреждённым» (битые символы). Победа: «Файл восстановлен» — обрывок блокнота (`story/notes.json → note`) и фрагмент главы (`text`), носитель +6. Провал: «Файл повреждён», −5.
- Пролог «Разрез коры» (`minigames/probe.js`), всего 10 минут. Часть 1 (до 3 мин): цельная планета — вращение пальцем, щипок/колесо — зум; точка атмосферы → данные → зонд; участок поверхности → площадка → посадка; скан масс; помехи от стихий. Часть 2 — выбор режима: «Быстрые приказы» (`raid/quick.js`: 16 узлов на вращаемой планете, штурм за СНК/НТ, подкрепление, закрепить, отозвать, запросы принять/отклонить, баланс) или «Тактика» (`minigames/raid/`): 4 точки (свободна, НТ, СНК, неизвестные) → гексагональный сектор 20×20 (свободная камера: палец — двигать, два пальца — зум/поворот/наклон, ПКМ — поворот) с вышками/шахтами/блок-постами. Запросы НТ/СНК (разведка, захват, подкрепление, проход колонны, зачистка): отказ −12 силы, иначе высадка с базы заказчика; резерв 25 отрядов (штурмовой 1Б 5С 1Л, закрепляющий 3Б 2С, разведка 3Л), 3 труповозки, 2 шаттла. Пешки Л/С/Б (5/7,5/10 БЕ; дальность 5/3/2; рисунок пользователя: визоры и лицевые экраны). Дальность отряда: разведка 5, штурм 3, закреп 1 — дальше бьют только пешки с большей дальностью. Обзор при движении: 1 клетка (разведка 3); действие «Разведка» — 1 клетка (у разведки 3), разведчик выходит и возвращается. Контроль: занятое строение (вышка 3, пост 2, шахта 1) или оборона (1) — +1 БЕ, подсветка видна только при найденном источнике. Тела остаются на месте гибели: труповозка собирает (2 тела → 1 клон через 3 мин), иначе забирает противник или жрёт фауна. Фауна: нематоды, шипуны, фильтратор. Шаттл занимает воздух над клеткой, оба транспорта возят 1 отряд. Один отряд в клетке. Поведение пешек (`crowd.js`): ожидание — вразнобой, атака — Б впереди, С парами колонной, Л сзади; под атакой — дуга к нападающим; закрепление — снежные стенки или ямы; отход — огрызаются; коллизии. 6 действий, у каждого — сторона (НТ/СНК/нейтралитет) и окно подтверждения с бафами/дебафами по каждой пешке. Погода, туман войны, ИИ фракций. Цель — равновесие влияния. Кнопка «Пауза» — справочник всех правил. Реплики отрядов (`story/raid.json → barks`) — над плашкой, следуют за пешками, печатаются со звуком; дрожат, расплываются или встают чётко; при гибели обрываются и рассыпаются. Снаряжение пешек и фауны — цитаты из книги (`story/raid.json`).
- Режим разработчика: Настройки → «Режим разработчика» → код 474747 (`save dev`) — терминал без кода, все главы открыты.
- Глава 1 «Вторжение» — посадка в бурю (`minigames/landing.js`): прицел + джойстик, рычаги ФОРСАЖ (7–8% топлива)/ЗАХВАТ, молнии с громом, выбросы плазмы, иней, трещины стекла, искры, огни колонии, приборы, 2 минуты, 3 захвата, угрозы (порыв, лёд, термальный пузырь), переговоры с «Горном-12» и реплики экипажа выплывают из-за краёв, финал — открытие ангара.
