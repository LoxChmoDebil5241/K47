# K47 — 3D хоррор-новелла (Unity)

## Суть
Игрок сидит в тёмной бетонной комнате. Камера от первого лица, без ходьбы — только поворот головы (360°).
- Прямо: терминал (ЭЛТ-монитор) — на нём идёт сама новелла.
- Справа: стол с блокнотом — заметки/улики, открываются кликом.
- В терминале 48 глав, в 47 из них — разные мини-игры (`docs/Minigames.md`).
- Сзади: проход в тёмный коридор — источник угрозы.
- Слева: стена — место для скримеров, надписей, изменений окружения.
Полный дизайн: `docs/GDD.md`.

## Стек
- Unity 6 (LTS), рендер URP, C#.
- Ввод: Input System (new).
- Текст: TextMeshPro.
- Сценарий новеллы хранится в данных (JSON/ScriptableObject), не в коде.

## Структура
```
Assets/
  Scripts/
    Core/        GameManager, состояния, сохранения
    Camera/      поворот головы, фокус на объектах
    Terminal/    вывод текста, печать посимвольно, выборы
    Notebook/    блокнот, записи
    Story/       загрузка и исполнение сценария
    Horror/      события: свет, звук, скримеры
    Minigames/   47 мини-игр терминала, общий интерфейс IMinigame
  Story/         файлы сценария (.json)
  Art/ Audio/ Materials/ Prefabs/ Scenes/
docs/            GDD и документация
```

## Правила кода
- Namespace `K47.<Папка>`, один класс — один файл.
- Никакой логики сюжета в MonoBehaviour — только в Story.
- Связь систем через события (C# events), без жёстких ссылок где можно.
- Комментарии и тексты игры — на русском.

## Ограничения среды Claude
Claude не может запустить Unity в облаке: код пишется «вслепую».
После каждого шага пользователь проверяет в редакторе и присылает скриншоты/ошибки консоли в чат.
Файлы пользователь присылает прямо в чат.
